# Justin Ng — Resume Website

A one-page site for STATS 140XP featuring an introduction, UCLA education, a concise experience list, LinkedIn contact, and a linked résumé.

## Files

- `index.html` — website and styles
- `resume.pdf` — attached résumé
- `README.md` — these instructions

## Reproduce locally

1. Download this repository (Code → Download ZIP) or clone it.
2. Extract the files into the same folder.
3. Open `index.html` in your web browser. No installation or build is needed.
4. Use the **View Resume** link to open the PDF.
